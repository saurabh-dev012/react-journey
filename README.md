A hands-on React learning repository focused on small, practical projects that build real frontend skills from fundamentals to more interactive app patterns.

## Overview

This repository is a collection of mini projects created while learning React, Vite, state management, props, styling, and utility app development. Each folder acts as a focused exercise and helps reinforce specific concepts in a clean, beginner-friendly way.

## What you will learn

- JSX and component composition
- State updates and event handling
- Props and reusable UI patterns
- Tailwind styling and responsive layouts
- Form handling and validation
- Working with APIs and real data
- React fundamentals and project structure
- Vite-based frontend workflows

## Projects in this repository

| Folder | Stack | Description |
| --- | --- | --- |
| `01basicreact` | React + CRA | Basic React setup and JSX fundamentals |
| `01vitereact` | React + Vite | Modern Vite setup and starter app |
| `02counter` | React + Vite | Counter app using state updates |
| `03tailwindprops` | React + Vite + Tailwind | Reusable components and Tailwind styling |
| `04bgchanger` | React + Vite | Dynamic background color switching |
| `05passwordGenerator` | React + Vite | Password generator with controls |
| `currencyConverter` | React + Vite + Tailwind | Currency converter with conversion logic |
| `gallery-project` | React + Vite + Tailwind | Image gallery app with dynamic fetches and card-based UI |
| `form-handling` | React + Vite | Controlled form inputs and handling |
| `notes-app` | React + Vite + Tailwind | Notes app with add and delete note functionality |
| `customreact` | Vanilla JS + React internals | Understanding custom React behavior |

## Prerequisites

- Node.js
- npm

## Getting started

Clone the repository:

```bash
git clone https://github.com/saurabh-dev012/react-journey.git
cd react-journey
```

Run any app individually:

```bash
cd notes-app
npm install
npm run dev
```

Or for another project:

```bash
cd 02counter
npm install
npm run dev
```
