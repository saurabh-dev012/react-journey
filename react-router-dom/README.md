# React Router DOM Practice

A small React app built to practice React Router concepts such as nested routes, route parameters, navigation, and 404 handling.

## Features

- Home, About, and Courses pages
- Dynamic course detail route using params
- Nested product routes for Men, Women, and Kids
- BrowserRouter-based navigation
- Back and forward navigation buttons
- NotFound fallback page

## Tech stack

- React
- Vite
- React Router DOM

## Getting started

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```
