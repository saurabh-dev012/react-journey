# Gallery Project

A small React + Vite app built to explore reusable card components, API-driven content, and modern styling with Tailwind.

## Features

- Responsive gallery layout
- Reusable card component
- Dynamic data fetching with Axios
- Clean styling with Tailwind CSS
- Lightweight Vite-based setup

## Tech Stack

- React
- Vite
- Tailwind CSS
- Axios

## Getting started

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```
